=====================================================================
  Пак Lua-скриптов для проверки физики SAGE Engine
=====================================================================

Девять готовых скриптов, каждый проверяет свою часть физики "живьём" —
повесьте на объект в редакторе, нажмите Play и смотрите. У каждого файла
в начале — своя инструкция (что за объект нужен, какие компоненты на него
повесить, какие клавиши что делают). Здесь — только общий обзор и порядок
сборки минимальной тестовой сцены.

Скрипты пишутся во ВНЕШНЕМ редакторе (блокнот подойдёт) и правятся на
ходу — сохранили файл во время Play, изменения применились сразу, без
перезапуска.

---------------------------------------------------------------------
  Что в паке
---------------------------------------------------------------------

01_fps_controller.lua        — ходьба от первого лица + прыжок через
                                настоящий контроллер персонажа движка
02_drop_test_reporter.lua    — репортёр падения: провалилось тело в пол
                                или нет, ушло ли потом "всплытие"
03_rotation_lab.lua           — момент, удар в точку/в центр, угловая
                                скорость, заморозка осей — клавишами
04_force_thruster.lua         — постоянная сила: разгон одинаков на
                                любой частоте кадров
05_kinematic_platform.lua     — платформа-лифт толкает пассажира без
                                дрожи и проваливания
06_mesh_collider_dropper.lua  — падающие фигуры с коллайдером Convex
                                Hull, построенным по мешу
07_stress_crowd_dropper.lua   — 40 тел сразу: ничего не проваливается,
                                всё укладывается
08_rope_and_cut.lua            — груз на тросе (joint), трос можно
                                "перерезать" на клавишу
09_trigger_zone_monitor.lua    — зона-сенсор: вход/выход, подсветка

---------------------------------------------------------------------
  Быстрая сборка тестовой сцены
---------------------------------------------------------------------

1. Создайте новый проект (или откройте существующий) в SageEditor.
2. Скопируйте все .lua-файлы из этого пака в assets/scripts/ проекта.
3. Пол. Меню Object -> Plane, растяните Transform -> Scale (например,
   40x1x40). Добавьте компоненты Rigid Body (Static) и Collider —
   для Collider поставьте форму "Mesh": коллайдер построится прямо по
   этой плоскости, без единого ручного размера (это и есть новая форма
   коллайдера "по мешу" — см. docs/physics.md). Обычный Box тоже
   подойдёт, если форма "Mesh" не нужна для конкретной проверки.
4. На отдельные пустые объекты (Object -> Empty) повесьте скрипты
   02-09 — каждому свой объект, инструкция в шапке файла скажет, что
   ещё нужно (RigidBody/Collider/Is Trigger и т.д.). Расставьте их по
   сцене с запасом места, чтобы не мешали друг другу.
5. Игрок для 01_fps_controller.lua:
     - Object -> Empty -> назовите "Player", повесьте на него скрипт;
     - выделите Player, Object -> Camera — камера станет его ребёнком;
       поставьте ей высоту глаз, например Position (0, 1.6, 0);
     - в инспекторе скрипта на Player перетащите эту камеру в поле
       "Camera Object" (иначе скрипт откажется стартовать и напишет
       об этом в консоль — это ожидаемо, не баг).
6. Нажмите Play. Логи скриптов — в консоли редактора (обычно снизу).

---------------------------------------------------------------------
  О чём говорит консоль
---------------------------------------------------------------------

Каждый скрипт пишет в консоль редактора: с чем он стартовал, что
проверяет, и предупреждает, если на объекте не хватает нужного
компонента или настройки (например, "нет RigidBody" или "не стоит
галочка Is Trigger") — это не ошибка движка, а подсказка, что доделать
в сцене. Настоящая ошибка физики выглядела бы иначе: тело застряло бы
в полу, провалилось насквозь, дрожало на месте или отскакивало без
причины — собственно то, что этот пак и должен помочь заметить.
