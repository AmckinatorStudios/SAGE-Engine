# Тесты

- Правка поведения — с тестом, который на старом коде падает.
- Модульный тест — `tests/test_<область>.cpp` по образцу соседних
  (`tests/TestFramework.h`), подключить в `tests/CMakeLists.txt`.
- Кадровые проверки — `tests/render/Checks_*.cpp`, эталоны —
  `tests/render/references`. Эталон обновлять, только если изменение картинки
  задумано, и смотреть новый снимок глазами.
- Тест не отключать и не ослаблять ради зелёного прогона — чинить причину.
- Запуск — точечно (`/verify`), не весь набор ради одного теста.
