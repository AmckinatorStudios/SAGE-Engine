=====================================================
  SAGE EDITOR — как запустить
=====================================================

1. Распакуйте эту папку ЦЕЛИКОМ куда угодно
   (например, на Рабочий стол).

2. Откройте папку и запустите SageEditor.exe
   двойным щелчком.

Всё. Устанавливать ничего не нужно.


-----------------------------------------------------
  ВАЖНО: распаковывать нужно всю папку
-----------------------------------------------------

Не запускайте программу прямо из архива и не вынимайте
из папки один только SageEditor.exe.

Рядом с программой лежат папки:
   assets    — шрифт интерфейса и шейдеры (без неё
               редактор не запустится или будет без букв);
   runtime   — SagePlayer.exe, которым File -> Build Game
               собирает готовую игру (без него сборка
               игры откажется работать);
   templates — готовые проекты-шаблоны (из них создаётся
               "Витрина" в окне нового проекта);
   themes    — оформление редактора. Тем в меню
               "Окно -> Оформление" четыре, а положив сюда
               свой .json, можно сделать пятую — как это
               делается, написано в themes\README.txt;
   plugins   — пример плагина редактора.


-----------------------------------------------------
  ЕСЛИ WINDOWS РУГАЕТСЯ ПРИ ЗАПУСКЕ
-----------------------------------------------------

Windows может показать синее окно:
   "Система Windows защитила ваш компьютер"

Это не вирус и не поломка. Так Windows встречает любую
программу без платной подписи разработчика.

Что делать:
   1. Нажмите "Подробнее"
   2. Нажмите "Выполнить в любом случае"

Достаточно сделать один раз.


-----------------------------------------------------
  ЕСЛИ ПРОГРАММА НЕ ЗАПУСКАЕТСЯ
-----------------------------------------------------

Рядом с SageEditor.exe появится файл sage_editor.log —
в нём записано, что произошло. Пришлите его, и по нему
будет видно причину.

Самая частая причина — старая видеокарта или очень
старые драйверы. Программе нужен OpenGL 3.3; ему больше
десяти лет, но на совсем древних встроенных видеокартах
его может не быть. Обновление драйверов видеокарты
обычно решает вопрос.


-----------------------------------------------------
  С ЧЕГО НАЧАТЬ
-----------------------------------------------------

При запуске откроется окно запуска: "Новый проект" или
"Открыть проект". Новый проект создаёт папку со сценой,
которую можно сразу редактировать — добавлять объекты,
свет, камеры, скрипты (меню Create), запускать Play и
собирать готовую игру (меню File -> Build Game).

Начать проще всего с шаблона "Витрина": это готовый
проект целиком — восемь участков (материалы, текстуры,
физика, частицы, свет, небо, анимация, скрипты), по
которым можно походить от первого лица и тут же править
их скрипты, глядя на результат.


-----------------------------------------------------
  ПЛАГИН-ПРИМЕР
-----------------------------------------------------

В папке plugins лежит example_stats — демонстрационный
плагин редактора (показывает, как выглядит собственная
панель поверх API движка). Редактор работает и без него;
если его нет или он не загрузился, в интерфейсе просто
не появится его панель — на остальную работу это не
влияет.
