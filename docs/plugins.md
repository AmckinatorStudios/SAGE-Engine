# Плагины

Плагин добавляет в SAGE то, чего нет «из коробки»: пункт меню, окно-инструмент
в редакторе, возможность для игры. Пишется на **Lua** — том же языке, что и
скрипты объектов. Компилятор, сборка и пересборка под каждую версию не нужны:
сохранили файл — плагин перезапустился.

## Быстрый старт: свой плагин за минуту

1. **Плагины → Создать плагин…**
2. Введите имя, выберите, что он делает:
   - **Инструмент редактора** — пункты меню и окна в редакторе;
   - **Возможность игры** — работает в Play и в собранной игре;
   - **Оба**.
3. Выберите, где он будет лежать:
   - **Этот проект** — уедет вместе с проектом в игру;
   - **Мои плагины** — во всех проектах, только редактор.
4. **Создать.** Откроется `editor.lua` (или `runtime.lua`) с рабочим примером:
   - пункт меню «Поставить куб над выделенным»;
   - окно «Ряд объектов».

Найти плагин можно в меню **Плагины**. Правьте файл и сохраняйте — изменения
подхватываются сами.

Встроенный пример — плагин **«Расстановка»**: копии выделенного объекта
сеткой, по кругу или вразброс. Его файлы — в `plugins/scatter/` рядом с
редактором. Скопируйте папку в «Мои плагины» и правьте под себя.
Встроенные плагины по умолчанию **выключены** — включите нужный в окне
«Плагины» (выбор запоминается в настройках редактора).

## Окно «Плагины»

**Плагины → Управление плагинами…** — всё о плагинах в одном месте.

- **Галка** слева от имени включает и выключает плагин. Состояние запоминается:
  - у плагина проекта — в его `plugin.json`, поэтому выключенный плагин не
    работает и в собранной игре;
  - у остальных — в настройках редактора.
- **Подробности** справа:
  - автор и описание;
  - есть ли часть редактора и часть игры;
  - работает ли плагин; если упал — ошибка с номером строки.
- **Кнопки:**
  - **Перечитать**;
  - **Открыть папку**;
  - **editor.lua** и **runtime.lua** — открыть файл в редакторе кода;
  - **Убрать** — удаляет папку плагина с диска.
- **Настройки** — переменные верхнего уровня `runtime.lua` и значения
  `settings` из `plugin.json`. Правятся прямо в окне и пишутся в `plugin.json`.
- **Установить…** — папка плагина, `plugin.json` или `.zip`. Галка
  «Устанавливать в проект» выбирает, куда установить: в проект или в «Мои
  плагины». Если такой плагин уже есть, новая версия заменяет старую.
- **Фильтр:** Все / Проект / Мои / Встроенные / C++.

## Как устроен плагин

```
plugins/hello/
  plugin.json   — что это за плагин
  editor.lua    — часть редактора (необязательна)
  runtime.lua   — часть игры (необязательна)
```

```json
{
  "id": "hello",
  "name": "Привет",
  "version": "1.0.0",
  "author": "Я",
  "description": "Что делает плагин",
  "enabled": true,
  "editor": "editor.lua",
  "runtime": "runtime.lua",
  "settings": { "message": "Привет!", "speed": 5 }
}
```

- `id` — имя папки и ключ для `plugins.Get`. Если его нет, берётся имя папки.
  «Создать плагин» делает его из названия: «Счётчик монет» → `schetchik_monet`.
- `editor` и `runtime` указывают, какие части есть. Нужна хотя бы одна.
- `settings` — простые значения (число, строка, да/нет). Файл пишут и руками.

### Где лежат плагины

| Где | Папка | Часть редактора | Часть игры |
|---|---|---|---|
| Встроенные | `plugins/` рядом с редактором | да | нет |
| Мои | `<настройки>/plugins` (кнопка «Папка «Мои плагины»») | да, во всех проектах | нет |
| Проект | `<проект>/plugins` | да | да, в Play и в игре |

Часть игры работает только у плагинов проекта: собранная игра несёт с собой
только проект.

Если `id` совпал, плагин проекта сильнее «моего», а «мой» сильнее встроенного.

## Часть редактора: `editor.lua`

Выполняется в редакторе, в **своём** состоянии Lua. Скрипты игры его не видят,
а ошибка плагина не роняет Play.

```lua
-- Пункт в меню «Плагины». Всё, что он сделает со сценой, отменяется ОДНИМ Ctrl+Z.
editor.menu("Поднять выделенное", function()
    for _, obj in ipairs(editor.selection()) do
        local p = obj.position
        obj.position = { x = p.x, y = p.y + 1, z = p.z }
    end
end)

-- Своё окно. Открывается из меню «Плагины» и помнит, открыто ли.
local count = 5
editor.panel("Мой инструмент", function()
    count = ui.int("Сколько", count, 1, 100)
    if ui.button("Создать") then
        for i = 1, count do
            editor.create("shape.sphere", "Шар " .. i).position = { x = i * 2, y = 1, z = 0 }
        end
    end
end)

-- События
editor.on("selection", function(obj) if obj then editor.log("выделен " .. obj.name) end end)
```

### `editor.*`

| Функция | Что делает |
|---|---|
| `editor.menu(подпись, fn)` | пункт в меню «Плагины». Несколько пунктов собираются в подменю с именем плагина |
| `editor.panel(заголовок, fn)` | окно; `fn` рисует его каждый кадр через `ui.*`. Окно — обычная панель редактора: оно в меню «Окно» → «Плагины» и «Плагины», в палитре команд (Ctrl+K), докается и помнит, открыто ли |
| `editor.on(событие, fn)` | события: `update` (dt), `selection` (объект или nil), `play`, `stop`, `project` |
| `editor.selected()` | главный выделенный объект или nil |
| `editor.selection()` | все выделенные — список |
| `editor.select(obj или список)` | выделить |
| `editor.objects()` | все объекты сцены в порядке списка |
| `editor.find(имя)` | объект по имени или nil |
| `editor.create(вид, имя?)` | объект из каталога «Создать»: `"empty"`, `"shape.cube"`, `"light.point"`… |
| `editor.kinds()` | все виды для `create` |
| `editor.duplicate(obj)` | копия с потомками, у того же родителя |
| `editor.undo_point()` | начать новый шаг отмены внутри одного вызова |
| `editor.log / warn / error(текст)` | в консоль, с именем плагина |
| `editor.status(текст)` | строка состояния внизу |
| `editor.playing()` | идёт ли Play |
| `editor.project_dir()`, `editor.assets_dir()` | папки проекта |
| `editor.open(путь)` | открыть файл в редакторе кода |
| `editor.save_scene()` | сохранить сцену |
| `editor.settings`, `editor.save_settings()` | настройки из `plugin.json`; изменить таблицу и сохранить |
| `editor.graph_pin(тип, fn)` | своё поле значения этого типа в окне свойств узла SAGE AI Graph: `fn(v)` рисует через `ui.*` и возвращает новое значение (или nil) — см. [ai.md](ai.md) |
| `editor.graph_tool(подпись, fn)` | своя кнопка на панели графа: `fn({path, name, selected})` |
| `editor.plugin_id`, `editor.plugin_dir` | свой id и папка |

### Объект сцены

| Поле или метод | Что это |
|---|---|
| `obj.id` | номер объекта, только чтение |
| `obj.valid` | жив ли объект |
| `obj.name` | имя, правится |
| `obj.position`, `obj.rotation`, `obj.scale` | таблица `{x=, y=, z=}`; присвойте таблицу целиком |
| `obj.color` | `{r=, g=, b=}` у объектов с мешем, иначе nil |
| `obj.parent` | родитель или nil; присвоить объект или nil |
| `obj:children()` | список потомков |
| `obj:delete()` | удалить вместе с потомками |

Объект держит **номер**, а не ссылку. Его можно хранить между кадрами; если
объект удалили, `obj.valid` станет `false`.

### `ui.*` — виджеты для окна

Виджет возвращает **новое значение**:
`speed = ui.slider("Скорость", speed, 0, 10)`.

| Функция | |
|---|---|
| `ui.text(...)` | текст; аргументы через пробел, как `print` |
| `ui.heading(текст)`, `ui.hint(текст)` | заголовок с линией; серый пояснительный текст |
| `ui.button(подпись)` | true в кадр нажатия |
| `ui.checkbox(подпись, v)` | да/нет |
| `ui.slider(подпись, v, min, max)` | число ползунком |
| `ui.int(подпись, v, min?, max?)` | целое: ползунок, если заданы границы, иначе поле |
| `ui.number(подпись, v)` | число перетаскиванием |
| `ui.input(подпись, текст)` | строка |
| `ui.color(подпись, {r,g,b})` | цвет |
| `ui.combo(подпись, номер, {варианты})` | выбор из списка; номер с 1 |
| `ui.separator()`, `ui.same_line()`, `ui.space()` | раскладка |
| `ui.tooltip(текст)` | подсказка к предыдущему виджету |

Подписи виджетов в одном окне должны быть разными: одинаковые ImGui считает
одним элементом.

### Если плагин сломался

- **Ошибка в коде** пишется в консоль с файлом и строкой и видна в окне
  «Плагины». Плагин замолкает, пока его не перезапустят: падающий каждый кадр
  обработчик иначе забил бы консоль. Исправьте файл и сохраните — плагин
  перезапустится сам.
- **Бесконечный цикл** останавливается: вызов, который длится больше 2 секунд,
  прерывается с ошибкой «плагин работает дольше 2 секунд без перерыва».
  Редактор не виснет.
- **Неизвестное событие** в `editor.on` — ошибка с перечнем допустимых.

## Часть игры: `runtime.lua`

Это **обычный скрипт** с тем же API, что у скриптов объектов (`Debug`, `Input`,
`Scene`, `Physics`, …) и тем же жизненным циклом (`Start`, `Update`,
`FixedUpdate`, `LateUpdate`). Объект у него служебный: движок создаёт его сам
при запуске каждой сцены — в Play и в собранной игре.

- Его нет ни в списке сцены, ни в файле сцены.
- `Start` плагинов вызывается **раньше** `Start` объектов сцены.

```lua
-- plugins/coins/runtime.lua
start_coins = 0                 -- настройка (видна в окне «Плагины»)

local Coins = { total = 0 }
function Coins.add(n)
    Coins.total = Coins.total + n
    Debug.Log("Монет: " .. Coins.total)
end
plugins.Register("coins", Coins) -- отдать скриптам игры

function Start() Coins.total = start_coins end
```

```lua
-- скрипт монеты в игре
function OnTriggerEnter(other)
    local coins = plugins.Get("coins")
    if coins then coins.add(1) end   -- nil, если плагин выключили
    self.gameObject:Destroy()
end
```

| Функция | |
|---|---|
| `plugins.Register(id, таблица)` | отдать API скриптам игры. Зовите в теле файла, не в `Start` |
| `plugins.Get(id)` | API плагина или nil |
| `plugins.Has(id)` | есть ли такой |
| `plugins.List()` | id всех зарегистрировавшихся |

- **Настройки** — переменные верхнего уровня `runtime.lua`: `start_coins = 0`
  выше. Окно «Плагины» показывает их с видом и умолчанием из файла, а значение
  берёт из `plugin.json`.
- **Свои модули**: папка плагина входит в пути `require`, так что
  `require("util")` найдёт `plugins/coins/util.lua`.
- **Между сценами**: плагин запускается заново в каждой сцене. Если нужно
  пронести данные через смену уровня, используйте `Vars` или сохранение.

## Плагины C++

Скомпилированные библиотеки `.so`/`.dll` в `plugins/` рядом с редактором, по
контракту `editor/src/PluginAPI.h`. Подробности — в [редакторе](editor.md#плагины-редактора).

- Видны в окне «Плагины» (фильтр «C++»).
- По умолчанию **выключены**: код C++ работает без песочницы и
  пересобирается под каждую версию редактора. Включаются галкой по одному.
- Переменная `SAGE_EDITOR_PLUGINS=1` включает все разом — для CI и отладки.

Свои инструменты проще писать на Lua: ничего не нужно собирать.
