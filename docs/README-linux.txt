=====================================================
  SAGE EDITOR для Linux — как запустить
=====================================================

1. Распакуйте архив ЦЕЛИКОМ куда угодно:
      tar -xzf SageEditor-Linux.tar.gz

2. Запустите редактор:
      cd SageEditor-Linux
      ./SageEditor

Устанавливать ничего не нужно.


-----------------------------------------------------
  Что нужно системе
-----------------------------------------------------

Сборка сделана на Ubuntu 24.04 (x86-64). Подойдут Ubuntu 24.04 и
новее и другие дистрибутивы того же возраста (glibc 2.39+), с
X11 или XWayland и драйвером OpenGL 4.1+.

Если не запускается — посмотрите sage_editor.log рядом с
программой: в нём написана причина.


-----------------------------------------------------
  Что лежит рядом
-----------------------------------------------------

   assets   — шрифт интерфейса и шейдеры (без неё редактор
              не запустится или будет без букв);
   runtime  — SagePlayer, которым File -> Build Game собирает
              готовую игру;
   themes   — оформление редактора;
   sage_build — сборка игры без редактора (для CI и выпуска).

Журнал изменений — CHANGELOG.md.
