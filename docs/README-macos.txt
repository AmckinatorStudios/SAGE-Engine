=====================================================
  SAGE EDITOR для macOS — как запустить
=====================================================

1. Распакуйте архив SageEditor-macOS.zip — получится
   SageEditor.app. Перетащите его в «Программы»
   (или оставьте где удобно).

2. ПЕРВЫЙ запуск: щёлкните по SageEditor.app ПРАВОЙ
   кнопкой -> «Открыть» -> «Открыть».

   Почему так: программа не подписана сертификатом
   Apple (у проекта его нет), и обычный двойной щелчок
   macOS отклонит со словами «не удаётся проверить
   разработчика». Правый щелчок -> «Открыть» разрешает
   её один раз и навсегда.

   Если macOS пишет, что программа «повреждена», —
   это та же проверка. В Терминале:
       xattr -dr com.apple.quarantine /путь/к/SageEditor.app
   и запустите снова.

Сборка — для Mac на Apple Silicon (M1 и новее).


-----------------------------------------------------
  Что внутри SageEditor.app
-----------------------------------------------------

Contents/MacOS/
   SageEditor   — редактор;
   assets       — шрифт интерфейса и шейдеры;
   runtime      — SagePlayer, которым File -> Build Game
                  собирает готовую игру;
   themes       — оформление редактора;
   plugins      — плагин-пример (включается переменной
                  SAGE_EDITOR_PLUGINS=1).

Не вынимайте SageEditor из .app — без соседних папок
он не запустится или будет без букв.


-----------------------------------------------------
  Где лог и настройки
-----------------------------------------------------

Запущенный из Finder редактор пишет лог в
   ~/.config/sage/editor/sage_editor.log
Там же — восстановление сцены после падения.
Настройки и список проектов — в ~/.config/sage/.
Новые проекты по умолчанию — в ~/Documents/SAGE Projects.

Если что-то не запускается — причина в sage_editor.log.


-----------------------------------------------------
  Собранная игра на Mac
-----------------------------------------------------

File -> Build Game собирает папку с игрой: в ней
программа SagePlayer (переименованная под игру) и
папка project. Запускается двойным щелчком (при первом
запуске — так же правой кнопкой -> «Открыть»).

CHANGELOG.md рядом с архивом — что изменилось на пути к 1.0.
