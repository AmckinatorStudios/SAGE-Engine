# Слои и порядок

## Три ступени

Итоговый порядок отрисовки определяется ровно тремя вещами:

```
слой (Layer) → порядок среди соседей (Order) → место в дереве
```

и больше ничем. Никаких скрытых правил.

Одного числа `z` не хватает: всплывающая подсказка и элемент HUD конкурировали
бы за него, и любое добавление элемента ломало бы чужую расстановку.

## Рекомендуемая шкала слоёв

| Слой | Что там |
|---|---|
| 0 | фон |
| 10 | оверлей поверх мира |
| 20 | HUD |
| 30 | меню |
| 40 | всплывающие окна |
| 50 | подсказки |
| 100 | отладка |

Это соглашение, а не встроенное правило: движок не знает, что такое HUD.

## Ключ сортировки

Раскладка складывает три ступени в одно 64-битное число `UIResolvedNode::SortKey`.
По нему идёт и рисование, и поиск попадания курсором — отдельного порядка для
ввода нет намеренно, иначе «кликается не то, что видно» становится
неизбежностью.

## Прозрачность

```
итоговая = прозрачность холста × прозрачность предков × своя × эффекты
```

Прозрачность группы наследуется поддеревом: плавно спрятать панель — это одно
число на корне, а не проход скриптом по всем детям.

## Режимы наложения

`Normal`, `Add`, `Multiply`, `Screen`, `Overlay`, `Darken`, `Lighten` — свойство
узла. Перечисление здесь не «switch на всё», а словарь: система рисования знает,
какие состояния GPU соответствуют каждому режиму, и новый режим не трогает ни
дерево, ни раскладку, ни ввод.
