# Формат документа

## Что это

`.uidoc` — JSON. Читается глазами, диффается в ревью, версионируется.

```json
{
  "ui_version": 1,
  "name": "MainMenu",
  "canvas": { "scale": 1, "reference": [1920, 1080], "match": 0.5 },
  "nodes": [
    { "id": 1, "guid": "n00000001", "name": "Root",
      "components": [
        { "type": "transform", "Size": [400, 200], "AnchorMin": [0.5, 0.5] },
        { "type": "fill", "Color": [0.1, 0.11, 0.14, 0.9], "Radius": [12,12,12,12] }
      ],
      "children": [ … ] } ],
  "theme": { … }
}
```

## Почему его нельзя рассинхронизировать с кодом

В сериализаторе нет ни одной строки «поле за полем». Он ходит по реестру
компонентов и по их таблицам свойств. Свойство, добавленное в компонент,
сохраняется само; забыть его негде.

## Чужой компонент не теряется

Документ, сохранённый сборкой с плагином, открывается сборкой без него — и при
следующем сохранении чужие данные остаются на месте (`UIUnknownComponent`
хранит исходный JSON как есть).

Без этого одно открытие файла молча уничтожает чужую работу.

## Версии и переезд

В файле записана `ui_version`. Читатель прогоняет цепочку миграций до текущей.

* новое свойство со значением по умолчанию **не ломает** старые файлы: его
  просто нет в файле, и значение берётся из конструктора компонента;
* версия растёт только при несовместимом изменении формата;
* файл из более новой сборки читается «как умеем», с честным предупреждением в
  `UILoadReport::Warnings`. Отказ читать вовсе хуже: человек теряет доступ к
  своей работе.

## Отчёт о чтении

```cpp
UILoadReport r = UILoadDocument(doc, path, &theme);
r.Ok;          // разобралось ли
r.FromVersion; // версия файла
r.Nodes;       // сколько узлов прочитано
r.Warnings;    // что не так, но не смертельно
r.Error;       // что смертельно
```

Система не ломает интерфейс молча: отсутствующий шрифт, битая маска, неизвестный
компонент и невалидное значение дают безопасный откат плюс запись в отчёт и лог.

## Поддерево

`UISaveSubtree` / `UILoadSubtree` — тот же формат, что у документа. Два разных
формата для «файла» и «буфера обмена» неизбежно разъедутся. Используется для
копирования, отмены правки и префабов.

Guid'ы вставленной копии становятся своими: иначе две «одинаковые» кнопки в одном
документе, и ссылки указывают неизвестно на какую.
