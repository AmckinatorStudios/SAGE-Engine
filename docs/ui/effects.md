# Эффекты

## Стек, а не поля

Прежняя тень была двумя полями внутри заливки: одна тень, всегда снизу, всегда у
подложки. Ни второй тени, ни свечения, ни размытия, ни порядка их применения
выразить было нельзя, а «стеклянная панель» (размытый фон + полупрозрачная
заливка + рамка + свечение) не собиралась в принципе.

```cpp
UIEffects& fx = node.Ensure<UIEffects>();
UIDropShadow& s = fx.Ensure<UIDropShadow>();
s.Offset = {0, 8}; s.Blur = 22.0f; s.Color = {0,0,0,0.5f};
fx.Ensure<UIGlow>().Radius = 30.0f;
fx.MoveItem(1, 0);        // порядок значим
```

**Порядок в стеке значим**: размытие после подкраски и подкраска после размытия
дают разный результат.

## Явная стоимость

Каждый эффект говорит, что ему нужно от рисующего:

| Стадия | Что происходит |
|---|---|
| `Modulate` | только множитель цвета — дополнительных проходов нет вовсе |
| `Behind` | дополнительная геометрия ПОД узлом (тень, свечение) |
| `Front` | геометрия ПОВЕРХ узла (внутренняя тень, блик) |
| `Offscreen` | промежуточная цель рисования (размытие) |

`UIEffects::NeedsOffscreen()` спрашивают ПЕРЕД тем, как создавать цель: «нет»
здесь означает ноль дополнительной работы.

Узел без эффектов не платит ничем: ни целью, ни проходом, ни веткой в шейдере.
Это проверяется тестом — простая заливка даёт ровно одну команду рисования.

## Встроенные эффекты

| Эффект | Стадия | Параметры |
|---|---|---|
| `UIDropShadow` | Behind | Offset, Blur, Spread, Color |
| `UIInnerShadow` | Front | Offset, Blur, Spread, Color |
| `UIGlow` | Behind / Front | Color, Radius, Intensity, Inner |
| `UIBlur` | Offscreen | Radius, Passes, Backdrop |
| `UIColorEffect` | Modulate | Tint, Brightness, Contrast, Saturation, Opacity |

## Тень — одна команда

Тень выдаётся **одной командой с мягким краем**, а не десятком расширяющихся
прямоугольников с падающей прозрачностью. Десяток — это десяток квадов на каждую
панель и заметная ступенчатость на большом радиусе.

Форма тени и свечения берётся у того, что нарисовано (скругление заливки,
картинки или формы), а не у прямоугольника узла: свечение квадрата вокруг
круглой иконки сразу выдаёт подделку.

## Свой эффект

```cpp
struct MyRipple : UIEffectOf<MyRipple> {
    static const UIEffectType& StaticType();   // Id, Stage, таблица свойств
    float Speed = 1.0f;
};
UIEffectRegistry::Instance().Register(MyRipple::StaticType());
```

Ядро рисования об этом не меняется. Подробности — в [extending.md](extending.md).
