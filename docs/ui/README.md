## Пять строк, с которых стоит начать

```cpp
#include "sage/ui/UIFramework.h"

sage::ui::UIRuntime ui;                       // документ + раскладка + ввод
ui.Context().Fonts = &fonts;                  // мост к ресурсам движка
ui.Context().Textures = &textures;

sage::ui::UINode* hello = ui.Doc().Create("Hello");
hello->Ensure<sage::ui::UIText>().Text = "Привет";

ui.Update(dt);                                // посчитать
ui.Render(backend);                           // нарисовать
```

Ни маски, ни эффекты, ни стили, ни промежуточные цели рисования здесь не
участвуют — и не стоят ничего. Сложность появляется ровно тогда, когда её
попросили.

## Главная граница

```
UI Core   ≠   Game Logic
```

Система интерфейса знает про прямоугольники, текст, маски, слои и нажатия. Она
не знает про здоровье, патроны, инвентарь и меню паузы. Кнопка сообщает
«меня нажали» и, если задана, свою команду-строку. Что эта строка означает,
решает игра — снаружи.

Это не стилистическое требование. Как только интерфейс начинает знать про
игровые понятия, он перестаёт быть переиспользуемым: его нельзя ни перенести в
другую игру, ни протестировать без неё, ни отредактировать в редакторе, который
про эту игру ничего не знает.
