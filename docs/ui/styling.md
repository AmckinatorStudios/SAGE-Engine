# Стили, состояния, тема

## Токены

Именованные значения вместо чисел в узлах:

```cpp
tokens.SetColor("Color.Accent", UIColorFromHex("#F2C230"));
tokens.SetNumber("Spacing.Medium", 16.0f);
tokens.SetNumber("Radius.Large", 18.0f);
```

Интерфейс, у которого отступы записаны числами по вкусу в каждом узле,
перестроить нельзя: «сделать всё чуть плотнее» означает пройти по трёмстам
узлам.

## Стиль

Стиль — набор значений свойств, наложенный на узел. Не отдельный вид узла и не
наследование классов: любой узел может носить любой стиль.

```cpp
UIStyle& s = theme.Ensure("ButtonPrimary");
s.Parent = "Button";                       // наследование стилей
s.Values = { {"fill", "Color", "@Color.Accent"} };
s.States["hover"] = { {"fill", "Color", "@Color.Border"} };
```

Значения адресуются строками («компонент», «свойство»), а не типами: стиль не
должен зависеть от того, какие компоненты существуют в этой сборке.

`@Имя.Токена` разрешается темой при применении.

## Приоритет

Документирован и детерминирован, потому что «почему у этой кнопки другой цвет» —
второй по частоте вопрос после «почему её не видно»:

```
1. значения по умолчанию компонента        — слабее всех
2. стиль темы для типа виджета             ("Button")
3. именованный стиль узла                  (UIStyled::Style)
4. стиль состояния                         ("Button:hover")
5. локальные значения прямо в узле         — сильнее всех
```

Пятый пункт сильнее всех намеренно: правка «вот здесь и вот сейчас» обязана
работать без разбирательства с темой. Чтобы это не превращалось в хаос, узел
помнит, какие свойства заданы локально (`UIStyled::Overrides`) — редактор их
подсвечивает и умеет сбросить, а тема их не трогает.

## Состояния

`hover`, `pressed`, `focused`, `disabled`, `selected`, `checked` применяются
поверх базовых значений в фиксированном порядке. Порядок важен: «нажата и под
курсором» обязано выглядеть как нажата.

Состояние здесь — **визуальное**. «Выбран» — это подсветка строки списка, а не
«выбранное оружие игрока».

## Тема

`UITheme` = токены + стили. Отдельный ресурс (`.uitheme`), сохраняется рядом с
документом или отдельно. Тема по умолчанию — нейтральная тёмная, одна и та же в
движке и в редакторе: «как это будет выглядеть в игре» не должно зависеть от
того, где смотришь.

```cpp
theme.Apply(doc);                 // по всему документу
theme.ApplyTo(node, stateFlags);  // по одному узлу
```
