# Граница API движка: что из engine/src/sage обещано, а что нет.
#
# ЗАЧЕМ. Игре был доступен любой заголовок движка, и всё внутреннее
# фактически становилось обещанием: убрать или переделать внутренний класс
# значило сломать неизвестно чью игру. Здесь обещание записано явно, а
# scripts/check_api.py сторожит, чтобы игра и редактор не включали лишнего.
#
# УРОВНИ (пути — от engine/src/sage, включаются как "sage/<путь>"):
#   [public] — API игр: то, что включает код игры (её Layer, компоненты, свой
#              кадр). С 1.0 ломается только со сменой мажорной версии.
#              Скриптам обещан не C++, а скриптовый API — editor/assets/api/sage.lua
#              (генерируется из Bind(...), свежесть: gen_script_api.py --check).
#   [tools]  — для приложений самого движка: редактор, плеер (runtime/),
#              sage_build, sage_api. Играм НЕ обещано, меняется без
#              предупреждения.
#   всё прочее — ВНУТРЕННЕЕ: включает только engine/src (и модульные тесты).
#              Сюда же реализации вне sage/ (engine/src/rhi, engine/src/physics).
#
# ПРАВИЛА (их проверяет сторож):
#   - Публичный заголовок включает только публичные, инструментальный — только
#     публичные и инструментальные: иначе внутреннее протекает транзитивно и
#     становится обещанием само.
#   - Новый заголовок по умолчанию внутренний. Обещание — отдельное решение:
#     добавить строку сюда. Перевод tools -> public ничего не ломает, обратный
#     перевод ломает игры — поэтому сомнительное держим в [tools].
#   - Убрать заголовок из [public] до 1.0 можно, оставив на старом пути мост
#     SAGE_FORWARD_HEADER (docs/architecture.md, «Переезд файла не ломает игры»).
