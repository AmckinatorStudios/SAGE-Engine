# Voxel World — блочная песочница на своём рендерере SAGE

Отдельная игра, **не часть движка**: собирается только по запросу —

```bash
cmake -B build -DSAGE_BUILD_VOXELWORLD=ON
cmake --build build --target VoxelWorld
cd build/games/voxelworld && ./VoxelWorld
```

Весь кадр рисует свой рендерер игры (`src/VoxelPipeline.h`) инструментами
движка — граф кадра, свои шейдеры и материалы, вычислительный шейдер, своя
пост-обработка (см. `docs/render_pipeline.md`). Ни одного штатного PBR-прохода.

## Кадр

| Проход | Тип | Что делает |
|---|---|---|
| Меши чанков | свой | пересборка изменённых чанков в GPU-буферы, ближние первыми, в бюджете кадра |
| Карта света / (CPU) | вычисления / свой | 16×16 «(небо, свой уровень) → цвет»: день, ночь, закат, мерцание |
| Небо | графика | градиент, квадратные солнце и луна, звёзды, плоские облака |
| Чанки | графика | глухие блоки и листва (вырез по альфе), сглаженный свет и AO в вершинах, туман |
| Вода и стекло | графика | смешивание, чанки от дальних к ближним, волна в вершинном шейдере |
| Рамка блока | графика | контур блока под прицелом |
| Пост: подводный, тон и виньетка | цепочка | свои эффекты; подводный — только когда камера в воде |
| Интерфейс | графика | расширение графа: прицел, панель блоков, отладка (F3 — время проходов) |

Свет хранится в мире: у блока два уровня 0..15 — небо и свой (светокамень,
тлеющий блок). Правка блока пересчитывает свет вокруг двумя очередями (снятие
и заполнение); самопроверка игры сверяет результат сотен случайных правок с
полным пересчётом.

Управление: WASD и пробел — ходьба и прыжок, F — полёт (Shift — вниз), ЛКМ —
сломать, ПКМ — поставить, 1–9 и колесо — блок, T — ускорить время, F3 —
отладка, F5 — пересобрать изменённые шейдеры (и раз в секунду само), Esc —
отпустить мышь / выйти. Размер мира — `SAGE_VOXEL_CHUNKS` (чанков по стороне),
время суток — `SAGE_VOXEL_TIME` (0..1), запасной путь карты света —
`SAGE_VOXEL_CPU_LIGHTMAP=1`.
